# The Stove Stayed Cold

One sentence, at most 280 characters, recalling a childhood memory — written
by `main.ts` to `/output/entry.txt`. The program self-gates: it writes only
if the sentence is 1–280 characters and not only white space, with no
trailing newline.

> Grandma's kitchen smelled of fried garlic and woodsmoke, and I only
> understood I would miss it the day the stove stayed cold.
